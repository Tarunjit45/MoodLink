# MoodLink 🎶✨

**MoodLink** is a modern, premium single-page application designed to "read the room" of your music. By analyzing Spotify playlist URLs through the lens of generative AI, MoodLink decodes the intangible vibes of your favorite tracks and presents them as a beautiful, shareable aesthetic profile.

## 🌟 The Vibe
MoodLink follows a **Glassmorphic** design language, featuring:
- **Soft Gradients**: Deep purples and indigos for a premium, midnight atmosphere.
- **Translucent UI**: Blurred backgrounds and subtle borders for a high-end feel.
- **Fluid Animations**: Smooth transitions and pulsing decorative orbs.

## 🚀 Key Features
1. **Instant Vibe Check**: Paste any public Spotify playlist URL and let the AI analyze its energy.
2. **Vibe Score**: A dynamic meter showing the balance between *Chill* and *Chaotic* energy.
3. **Aesthetic Palette**: Five hex codes generated to match the visual mood of the music.
4. **AI-Style Poetics**: A custom-generated, 2-line poetic description of the playlist's "soul."
5. **Share to X**: Seamless integration to share your unique vibe profile with your social circle.

## 🛠️ Technical Stack
- **React (v19)**: Powering the reactive UI and state management.
- **Tailwind CSS**: Providing the utility-first styling and glassmorphic effects.
- **Google Gemini API**: Utilizing the `gemini-3-flash-preview` model for advanced content analysis and creative generation.
- **Lucide Icons**: Clean, consistent iconography throughout the app.
- **ESM.sh**: Direct module importing for a lightweight, build-less feel in production.

## 📖 How It Works
MoodLink uses the **Google Gemini API** to simulate a deep "listening" session. Since the API does not browse live private URLs directly, it uses the context of the playlist title and URL structure to creatively interpret the musical energy, providing a consistent "aesthetic guess" that feels remarkably accurate to the user.
